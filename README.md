# 텔레그램 → 인스타 카드뉴스/릴스 자동 업로드 봇

이슈 매거진 스타일(사진 풀블리드 + 굵은 제목 카드뉴스, 상단 제목 고정 + 가운데 영상 릴스)로
카드뉴스와 릴스를 만들어 인스타에 올립니다.

## 쓰는 법 (기본: 직접 업로드 모드)

봇에 주제, 링크, 다른 채널 메시지(사진·영상 포함)를 보냄
→ [카드뉴스 | 릴스] 선택 → 결과물 + 캡션이 텔레그램으로 옴
→ [📎 원본 파일로 받기 | ✏️ 수정 요청 | 🔄 다시 생성 | 🔀 형식 전환 | ✅ 완료]
→ 저장해서 인스타 앱으로 직접 업로드 (캡션은 박스 눌러서 복사)

필요한 건 텔레그램 봇 토큰과 Claude API 키뿐입니다. 인스타 API, R2 설정은 필요 없어요.
나중에 자동 게시가 필요하면 `UPLOAD_MODE=api`로 바꾸고 IG/S3 설정을 채우면 됩니다.

## 사진/영상은 어디서?

1. 보낸 메시지나 수집한 채널 글에 붙은 사진/영상 (출처 자동 표기)
2. 없으면 Pixabay 무료 스톡 사진/영상 (`PIXABAY_API_KEY` 설정 시)
3. 그것도 없으면 검은 배경 텍스트 디자인

카드뉴스: 첨부 사진이 커버부터 순서대로 들어가고, 영상만 있으면 한 장면을 캡처해서 씀
릴스: 영상 하나를 여러 장면에 쓰면 끊기지 않고 이어서 재생됨

## 사용법

| 입력 | 동작 |
|---|---|
| 텍스트 / 링크 / 포워드 / 사진·영상 (여러 장 묶음 가능) | 형식 선택 버튼 |
| `/card 주제`, `/reel 주제` | 바로 생성 |
| 메시지에 답장으로 `/card` 또는 `/reel` | 그 메시지(사진·영상 포함)로 바로 생성 |
| `/collect` | 채널 수집 지금 실행 |
| `/limit` | 인스타 게시 한도 확인 |
| ✏️ 수정 요청 후 텍스트 | 피드백 반영 재생성. `캡션:`으로 시작하면 캡션만 교체 |

텔레그램 봇은 20MB 넘는 파일을 받을 수 없습니다. 큰 영상은 채널 자동 수집 쪽으로 들어오게 하세요 (80MB까지).

## 기본 세팅

채팅에서 안내한 순서대로: 텔레그램 봇 → Claude API → 인스타 프로페셔널 전환 → Meta 앱/토큰 → R2 → 실행.

## 추가 세팅 1: Pixabay (무료, 5분)

1. pixabay.com 가입 → 이메일 인증
2. 로그인한 상태로 pixabay.com/api/docs 접속 → 페이지 위쪽 `key (required)` 줄에 내 키가 보임
3. `.env`의 `PIXABAY_API_KEY`에 붙여넣기

## 추가 세팅 2: 채널 자동 수집 (10분)

봇은 남의 채널을 못 읽어서 **내 텔레그램 계정**으로 읽습니다.

1. PC 브라우저로 **my.telegram.org** 접속 → 전화번호(+8210...) 입력 → 텔레그램 앱으로 온 코드 입력
2. **API development tools** → App title, Short name 아무거나 → Create
3. 나오는 `api_id`(숫자), `api_hash`를 `.env`의 `TG_API_ID`, `TG_API_HASH`에
4. `.env`의 `SOURCE_CHANNELS`에 참고할 채널 입력 (공개 채널은 가입 안 해도 됨, 비공개는 내 계정이 들어가 있어야 함)
5. 터미널에서 한 번만:
   ```
   python login.py
   ```
   전화번호 → 텔레그램 앱으로 온 코드 → (2단계 인증 쓰면 비밀번호) 입력.
   채널별로 OK / 실패가 표시됩니다.
6. `python bot.py` 다시 실행 → 봇에 `/start` 보내면 "채널 자동 수집: 켜짐" 확인 → `/collect`로 테스트

`data/tg_user.session` 파일은 내 텔레그램 계정 열쇠입니다. 남에게 주거나 깃허브에 올리지 마세요.

## 커스터마이즈

| 바꿀 것 | 위치 |
|---|---|
| 브랜드명, 핸들, 계정 주제, 강조색, 고정 해시태그 | `.env` |
| 채널 목록, 수집 시간, 이슈 개수 | `.env` |
| 제목 톤, 캡션 형식, 장면 구성 | `content.py` (`COMMON_RULES`, `CARD_SPEC`, `REEL_SPEC`, `SELECT_SPEC`) |
| 레이아웃 | `render.py` |

## 참고

- 다른 채널의 사진/영상을 쓰면 저작권 문제가 생길 수 있습니다. 출처는 자동 표기되지만 권리 문제가 해결되는 건 아닙니다. 걱정되면 `MEDIA_FROM_SOURCE=false`.
- 진행 중 작업은 메모리에 있어서 봇을 재시작하면 미리보기 단계 작업은 사라집니다.
- Instagram API로는 인스타 음원 라이브러리를 쓸 수 없습니다. 음악은 `BGM_PATH`에 저작권 free mp3를 지정하세요.
